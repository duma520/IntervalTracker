## 第一部分：入门指南（写给所有人）

### 1. 什么是IntervalTracker？

**简单来说**：IntervalTracker（间隔追踪器）是一款帮助您记录**什么时间做了什么**，并自动计算**两次记录之间的时间间隔**的软件。

**专业定义**：一个基于Python和PySide6开发的跨平台桌面应用程序，支持多用户、多标识分类、间隔统计、数据备份恢复等功能，采用SQLite数据库存储数据，以马卡龙色系为视觉主题。

**核心思想**：记录生活、工作中的每一个重要时刻，通过时间间隔洞察规律、优化效率、提醒健康。

### 3. 快速开始——5分钟上手

#### 第一步：安装与启动
1. 确保电脑已安装Python 3.8+和PySide6（或直接下载打包好的exe文件）
2. 运行程序，首先看到的是**用户选择界面**

#### 第二步：选择或创建用户
![用户选择界面示意图]
- 如果是第一次使用，点击"添加用户"
- 输入显示名称（如"张三"），用户名可选
- 点击"登录"进入主界面

#### 第三步：添加第一条记录
1. 在左侧"新增记录"区域，选择**标识**（如"学习"）
2. **记录日期**默认为今天，**记录时间**默认为现在
3. 在**内容**框输入"开始学习Python"
4. 在**备注**框可选输入额外信息
5. 点击"保存记录"

**完成！** 您的第一条记录已保存。右侧记录列表会显示这条记录，下方"间隔"列会显示"首次记录"。

#### 第四步：添加第二条记录
1. 再次选择相同标识（"学习"）
2. 修改时间（比如设为2小时后）
3. 输入新内容"学习数据结构"
4. 点击"保存"

观察右侧记录列表，新记录下方"间隔"列会显示"2小时0分钟0秒"——这就是两次学习之间的时间间隔！

## 第二部分：基础操作（写给普通用户）

### 5. 用户管理——多用户支持

#### 为什么需要多用户？
- **家庭共用**：家人可以分别使用自己的账户，数据互不干扰
- **工作与生活分离**：同一人可创建"工作"和"生活"两个账户
- **多角色管理**：如教师可为每个班级创建不同账户

#### 操作步骤

##### 添加用户
1. 启动程序，在用户选择界面点击"添加用户"
2. 输入**显示名称**（必填，如"张三"）
3. 输入**用户名**（可选，系统会自动生成唯一用户名）
4. 点击"确定"

##### 切换用户
1. 在主界面工具栏点击"切换用户"
2. 在列表中选择要登录的用户
3. 点击"登录"

##### 编辑用户
1. 在用户选择界面选中用户
2. 点击"编辑用户"
3. 修改显示名称或用户名
4. 点击"确定"

##### 删除用户
1. 在用户选择界面选中用户
2. 点击"删除用户"
3. 确认删除（**注意：该用户的所有数据将被永久删除**）

#### 💡 小贴士
- 每个用户的数据库文件独立存储，删除用户时会同时删除其数据文件
- 用户名用于系统内部标识，一旦创建不建议修改

### 6. 标识管理——分类的艺术

标识是IntervalTracker的核心概念，用于对记录进行分类。每个标识都有独立的名称、描述和颜色。

#### 默认标识（开箱即用）

| 标识 | 描述 | 颜色 | 适用场景 |
|------|------|------|----------|
| 默认 | 默认分类 | 薄荷绿 | 未分类的记录 |
| 工作 | 工作相关记录 | 天空蓝 | 工作任务、会议、项目 |
| 生活 | 日常生活记录 | 苹果绿 | 家务、购物、日常琐事 |
| 学习 | 学习进度记录 | 薰衣草紫 | 学习、阅读、考试 |
| 运动 | 运动健康记录 | 蜜桃橙 | 跑步、健身、瑜伽 |
| 娱乐 | 娱乐休闲记录 | 柠檬黄 | 电影、游戏、音乐 |
| 健康 | 健康状况记录 | 薄荷绿蓝 | 用药、体检、康复 |
| 饮食 | 饮食记录 | 杏色 | 三餐、饮水、零食 |
| 其他 | 其他记录 | 焦糖奶霜 | 无法归类的记录 |

#### 自定义标识

##### 添加新标识
1. 点击工具栏"标识管理"
2. 点击"添加标识"
3. 填写以下信息：
   - **标识名称**（必填）：如"读书"
   - **描述**（可选）：如"阅读记录"
   - **颜色**：点击"选择颜色"或"随机"选择喜欢的马卡龙色
   - **排序**：数字越小越靠前
4. 点击"确定"

##### 编辑标识
1. 在标识管理列表选中标识
2. 点击"编辑标识"或双击该行
3. 修改信息后点击"确定"

##### 删除标识
- **无记录的标识**：直接永久删除
- **有记录的标识**：软删除（禁用），保留历史记录，但不再出现在标识选择列表中

##### 多选删除
1. 在标识管理界面点击"多选模式"
2. 勾选要删除的标识
3. 点击"删除选中"
4. 系统会提示哪些标识将被禁用（有记录），哪些将永久删除（无记录）

#### 一键恢复默认标识
1. 在标识管理界面点击"一键恢复默认"
2. 从下拉菜单中选择方案：
   - **基础方案**：简约7项标识
   - **工作生活方案**：11项工作与生活相关标识
   - **学习成长方案**：9项学习相关标识
   - **健康运动方案**：10项健康运动标识
   - **创意创作方案**：9项创意相关标识
   - **家庭消费方案**：20项家庭消费标识（新增！）
   - **完整方案**：69项覆盖各领域的全面标识

#### 💡 小贴士
- 使用不同的颜色区分标识，视觉上更容易识别
- 排序功能可以将常用标识放在前面
- 删除有记录的标识时，记录仍保留，只是标识被禁用

### 7. 记录管理——增删改查

#### 添加记录
1. 选择标识
2. 设置日期和时间（默认当前）
3. 输入**内容**（必填）
4. 输入**备注**（可选）
5. 点击"保存记录"

#### 查看记录
- 主界面右侧列表显示所有记录，按日期倒序排列
- 双击任意记录可打开编辑对话框
- 可通过顶部搜索框和标识筛选器快速定位记录

#### 编辑记录
**方法一**：双击列表中的记录
**方法二**：
1. 选中记录（单击行）
2. 右键菜单选择"编辑记录"
3. 修改信息后点击"确定"

#### 删除记录

##### 单条删除
1. 选中记录
2. 右键菜单选择"删除记录"
3. 确认删除

##### 批量删除
1. 勾选多条记录（或按Ctrl多选）
2. 点击工具栏"批量删除"按钮
3. 确认删除

##### 一键清空
1. 点击"一键清空"按钮
2. 系统显示统计信息（总记录数、各标识记录数）
3. 二次确认后永久清空所有记录

#### 查看详情
1. 选中记录
2. 右键菜单选择"查看详情"
3. 弹出详情窗口，显示完整信息，包括：
   - 基本信息（ID、标识、日期、时间）
   - 记录内容
   - 备注信息
   - 创建时间、更新时间
   - 与前一条记录的间隔
   - 累积间隔（与首次记录的间隔）

#### 💡 小贴士
- 右键菜单提供全选、取消全选、按标识筛选等快捷操作
- 双击查看详情窗口中的"编辑"按钮可快速跳转到编辑
- 删除记录**不可撤销**，重要数据请先备份

### 8. 间隔统计——核心价值

IntervalTracker最强大的功能是自动计算时间间隔，帮助您洞察规律、优化行为。

#### 两种间隔类型

| 类型 | 定义 | 意义 |
|------|------|------|
| **简单间隔** | 与**前一条**同标识记录的时间差 | 了解相邻两次活动的间隔，如两次服药的时间间隔 |
| **累积间隔** | 与**第一条**同标识记录的时间差 | 了解总时长，如从第一次学习到现在经过的时间 |

#### 间隔颜色提示

| 颜色 | 间隔长度 | 含义 |
|------|----------|------|
| 🟢 绿色 | < 1天 | 正常频率，保持 |
| 🔵 蓝色 | 1-7天 | 适度间隔，注意 |
| 🟠 橙色 | 7-30天 | 间隔较长，提醒 |
| 🔴 红色 | > 30天 | 间隔过长，警示 |

#### 间隔显示位置

1. **新增记录区**：选择标识后，自动显示距上次同类记录的时间
2. **记录列表**："间隔"列显示与前一条的间隔，"累积间隔"列显示与首次的间隔
3. **标识统计表**：各标识的最后一次间隔概览
4. **状态栏**：显示全局间隔统计（最短、最长、平均间隔）

#### 实际应用举例

**案例：服药提醒**
- 第一次记录："降压药，10:00"
- 第二次记录："降压药，12:00" → 间隔显示"2小时"
- 若间隔超过6小时，颜色变为红色提醒

**案例：学习追踪**
- 第一次记录："开始学习Python，9:00"
- 第二次记录："继续学习，14:00" → 间隔"5小时"
- 累积间隔显示从9:00到现在的总时长

### 9. 数据备份与恢复

数据安全是专业用户的关注重点。IntervalTracker提供完整的备份与恢复机制。

#### 备份管理器

每个用户拥有独立的备份目录：`/backups/{用户ID}/`

#### 手动备份
1. 点击工具栏"手动备份"
2. 进度条显示备份进度
3. 完成后显示备份文件信息（文件名、大小、耗时）
4. 备份文件自动命名为`manual_YYYYMMDD_HHMMSS.db`

#### 自动备份
- 程序每小时自动检查并创建一次备份
- 自动备份文件命名为`auto_YYYYMMDD_HHMMSS.db`

#### 备份管理界面
点击"备份管理"打开管理窗口，包含：

##### 左侧：备份列表
| 列 | 说明 |
|----|------|
| 备份时间 | 创建时间 |
| 备份类型 | 自动/手动/回滚 |
| 文件大小 | 备份文件大小 |
| 记录数 | 备份中包含的记录数量 |
| 操作 | 查看/恢复按钮 |

##### 右侧：备份信息
- 文件名
- 备份类型
- 备份时间
- 文件大小
- 记录数量
- 日期范围（最早到最晚记录）
- 数据库版本

#### 筛选功能
- **按类型筛选**：全部/自动/手动/回滚
- **按时间范围筛选**：自定义起止日期

#### 恢复备份
1. 在备份列表中选择要恢复的备份
2. 点击"恢复此备份"或行内的"恢复"按钮
3. 确认恢复（系统会自动创建当前数据的回滚备份）
4. 恢复成功后自动刷新数据

#### 删除备份
1. 选中备份
2. 点击"删除备份"或行内的"删除"按钮
3. 确认删除

#### 回滚点
恢复操作前，系统自动创建名为`rollback_YYYYMMDD_HHMMSS.db`的回滚备份，确保您随时可以回退到之前的状态。

#### 💡 高级技巧
- 定期手动备份重要数据
- 清理过期备份以节省磁盘空间
- 可在设置中调整最大备份数量（默认30）

### 12. 数据库结构详解

对于技术用户，理解数据库结构有助于数据分析和二次开发。

#### 数据库文件
- **用户数据库**：`.scheduling_system/users.db`（存储所有用户信息）
- **用户数据文件**：`.scheduling_system/user_{username}_{timestamp}.db`（每个用户独立的数据文件）

#### 核心表结构

##### categories（标识表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自动递增 |
| name | TEXT | 标识名称（唯一） |
| description | TEXT | 标识描述 |
| color | TEXT | 颜色值（十六进制，如#B5EAD7） |
| icon | TEXT | 图标（预留字段） |
| sort_order | INTEGER | 排序顺序 |
| is_active | INTEGER | 是否激活（1激活，0禁用） |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

##### scheduling_records（记录表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自动递增 |
| category_id | INTEGER | 外键，关联categories.id |
| record_date | DATE | 记录日期 |
| record_time | TIME | 记录时间 |
| content | TEXT | 记录内容 |
| notes | TEXT | 备注 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

##### db_info（数据库信息表）
| 字段 | 类型 | 说明 |
|------|------|------|
| key | TEXT | 主键，信息键名 |
| value | TEXT | 信息值 |

**常见键值**：
- version：数据库版本
- schema_version：架构版本
- created_at：数据库创建时间

##### user_settings（用户设置表）
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | INTEGER | 主键，关联users.id |
| settings | TEXT | JSON格式的设置数据 |

##### users（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键，自动递增 |
| username | TEXT | 用户名（唯一） |
| display_name | TEXT | 显示名称 |
| created_at | TIMESTAMP | 创建时间 |
| last_login | TIMESTAMP | 最后登录时间 |
| db_file | TEXT | 关联的数据文件名（唯一） |

#### 索引优化
为了提升查询性能，系统创建了以下索引：
- `idx_records_category_id`：按标识快速筛选
- `idx_records_date_time_category`：按日期时间标识组合排序
- `idx_records_content`：全文搜索优化
- `idx_categories_name`：按名称快速查找
- `idx_categories_sort`：按排序字段优化

#### 数据库升级机制
系统自动检测旧版本数据库，执行升级：
1. 检查是否有旧版`category`字段
2. 创建新表结构
3. 迁移数据
4. 删除旧表

FROM categories c
LEFT JOIN scheduling_records r ON c.id = r.category_id
WHERE c.is_active = 1
GROUP BY c.id
ORDER BY c.sort_order, c.name

```python
@staticmethod
def get_text_color(background_color: QColor) -> QColor:
    """根据背景色自动选择文字颜色"""
    # 计算亮度
    brightness = (background_color.red() * 299 + 
                 background_color.green() * 587 + 
                 background_color.blue() * 114) / 1000
    
    # 亮度阈值判断
    if brightness < 128:
        return QColor('#FFFFFF')  # 深色背景用白字
    else:
        return QColor('#2C3E50')  # 浅色背景用深灰
```

#### 设计优势
1. **视觉舒适**：长时间使用不易疲劳
2. **区分度高**：28种颜色足够区分各类标识
3. **自适应**：文字颜色自动调整，保证可读性

                record['record_date'],
                record['record_time'],
                record['content'],
                record.get('notes', '')
            ])

### 26. 常见问题解答（FAQ）

#### Q1：软件需要联网吗？
**A**：不需要，IntervalTracker是完全离线的桌面应用程序，所有数据都存储在本地。

#### Q2：数据会丢失吗？
**A**：程序内置了自动备份机制（每小时），您也可以手动备份。但建议定期将备份文件复制到其他位置。

#### Q3：如何迁移数据到另一台电脑？
**A**：找到`.scheduling_system`文件夹，复制整个目录到新电脑的相同位置即可。

#### Q4：支持导出为Excel吗？
**A**：当前版本不支持直接导出，但您可以通过SQLite浏览器打开数据库文件自行导出。

#### Q5：可以设置提醒吗？
**A**：当前版本无提醒功能，但可以通过观察间隔颜色判断是否需要行动。

#### Q6：最多可以创建多少个标识？
**A**：理论上无限制，但建议不超过100个，以免影响性能。

#### Q7：标识颜色可以自定义吗？
**A**：可以，编辑标识时可以选择任意颜色。

#### Q8：删除用户后数据还能恢复吗？
**A**：不能。删除用户会同时删除其数据库文件，请先备份。

#### Q9：支持快捷键吗？
**A**：当前版本支持基本的键盘操作，未来版本会增加快捷键。

#### Q10：软件会收集我的数据吗？
**A**：不会。所有数据仅保存在本地，我们不收集任何用户信息。
